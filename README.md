# Linear Algebra and Complex Numbers
This program is writen and rust and holds the math that Quantum Information needs to work that computers don't natively support. Such as Matrices, Imaginary Numbers, Vectors, and native type checking for each of them. 

For example a in probabilistic classical information, stochastic matrix must satify the following:
1. All entries are nonnegative real numbers
2. All columns have to be equal to 1

Another example in basic linear algebra is that the inside dimensions must be equal for you to multiply, otherwise it's an error.

This package makes sure all those are satified at compile time.
